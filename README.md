# resume-analyzer
AI Resume Analyzer

A Streamlit-based web application that analyzes resumes and provides skill-based insights.

Features
Upload Resume PDF
Extract Resume Text
Detect Technical Skills
Calculate Resume Score
Resume Rating (Beginner / Intermediate / Advanced)
Missing Skills Recommendation
Technologies Used
Python
Streamlit
PyPDF2
Pandas
How to Run
pip install -r requirements.txt
streamlit run app.py
